# Status

Last updated: 2026-05-28.

## Done

### Native macOS app
- Renamed the distributed app to `MediaFlow.app`; the internal SwiftPM target remains `ImageViewerNative`.
- Bundle version metadata is generated by `scripts/build-native-app.sh`.
- Production build script now uses SwiftPM release + whole-module optimization, strips symbols, ad-hoc signs, and verifies the generated app bundle.
- Added local DMG creation and verification scripts modeled after the SessionFlow release flow.
- Added optional Developer ID signing and a notarization helper for public release artifacts.
- Added SessionFlow-style icon generation rules in `docs/ICON_GENERATION.md`.
- Metal-backed collage canvas for images and videos.
- No main canvas toolbar; primary commands live in the macOS menu bar and hotkeys.
- macOS menu bar entries for Add, Save Playback, Load Playback, Open Last Closed Session, Forget Last Closed Session, Recent Playbacks, Clear All, Toggle Crop, Full Screen, Enlarge, Reduce, Zoom, Pan, and optional hover item tools.
- App menu entries for About MediaFlow, What's New, and Check for Updates.
- Masonry-style recursive layout fills the canvas without fixed rows/columns and scores for visible-content utilization.
- Hover item tools: Enlarge, Reduce, Zoom +, Zoom -, Pan. They are off by default and can be enabled from the View menu.
- Mouse wheel zooms the item under the pointer, clamped to 100% minimum.
- Zoom uses mipmapped image textures, anisotropic linear minification, and adaptive Lanczos 2 magnification in Best mode.
- Selected video bottom panel: icon buttons for play/pause, mute, solo, granular speed, time scrubber, clearer visual A-B segments, Set A, Set B, Clear A-B.
- Metal Quality diagnostic selector: Best, Linear, Nearest, Bicubic, and Lanczos 2.
- Optional Natural Denoise + Detail mode uses an edge-aware Metal denoise pass for noisy low-light images and videos.
- Native `.ivplayback` save/load stores encrypted file paths plus crop, pan, zoom, weights, volume, mute/speed, and A-B loops.
- `Q` quits immediately; physical key handling keeps hotkeys working across keyboard layouts.

### Ingest & layout
- Drag-and-drop and file-picker ingest for photos and videos
- Photos import is available from File -> Add From Photos, exporting selected Photos assets into MediaFlow's local support directory before adding them to the wall.
- Finder **Open With** ingest for selected images and videos, replacing the current scene as a fresh playback.
- Polished empty state with centered drop target, menu hints, and drag-over feedback.
- Duplicates allowed (every drop creates a distinct item, even of the same file)
- Native masonry/treemap layout fills the screen edge-to-edge.
- Auto-relayouts on every mutation: add, delete, reorder, crop, item weight change, window resize.
- Full content is visible by default; crop/zoom are explicit actions.

### Selection
- Click-to-select one active item.
- Dragging a cropped/zoomed item pans its visible content by default.
- `Shift` while dragging reorders items in the layout.
- `+` / `-` enlarge or reduce the selected item, or the item under the pointer.
- `1` / `2` set A/B for the hovered or selected video; `0` clears A-B.
- Arrow keys control the hovered or selected video: left/right seek, up/down speed.
- `Esc` exits fullscreen first; otherwise deselects / exits crop / exits pan. Clicking empty space deselects.
- `Del` / `Backspace` removes the selected item and recalculates layout.

### Manual layout
- Shift-drag-to-reorder: drag any item over another while holding `Shift`; drop inserts before the target.
- Enlarge/Reduce are available from hover controls, the Item menu, and `+` / `-`.
- Item weight is saved so proportions survive relayouts and layout files.

### Zone (crop to drawn aspect)
- Menu Crop or `Z` → drag a rectangle → that aspect ratio is applied to the target item.
- `Option`-drag an item to crop it directly without pre-selecting it or toggling crop mode.
- Crop is applied directly to the item where the crop gesture starts.
- The underlying file is unchanged. Crop, pan, and zoom are layout metadata.

### Videos
- Loop by default, sound enabled by default, autoplay on load.
- Per-video Pause / Play
- Per-video mute, temporary solo, and volume slider
- Speed `−` / `+` in 0.05× steps, clamped to 0.1×–8×
- Playback below 1× can use separately toggled Metal temporal frame blending to soften frame stepping; the toggle is saved between launches.
- Natural Denoise + Detail can be toggled from the View menu and is saved between launches.
- A-B clips: Set A and Set B immediately add an active clip once both points exist; additional A/B pairs append more clips.
- Physical `1` and `2` set A/B; physical `0` clears A-B.
- Playback monitor jumps through active A-B clips in sequence and wraps to the first clip after the last.
- Scrubbing the timeline or starting a new A-B temporarily releases the loop guard so new clips can be marked outside existing clips.
- Global freeze via `Space`. Pauses all videos; on resume restores each video's own pause/play state, speed, A-B loops, and playhead.

### Save / Load (`.ivplayback`)
- Encrypted playback file references local media by path.
- Stores per-item weight, crop, zoom, pan, video speed, volume, mute state, A-B loops, and Flow Library rotation settings.
- Load rebuilds the scene from files that still exist at those paths.
- Saved and opened playbacks are added to File -> Recent Playbacks.
- The app opens to a clean canvas by default.
- The last non-empty playback is saved automatically on quit, restored manually from File -> Open Last Closed Session, and deleted with File -> Forget Last Closed Session.
- Recent playback history can be cleared from the Recent Playbacks submenu.
- `CHANGELOG.md` is bundled into the app and shown from App menu -> What's New.
- Update checks query GitHub Releases and can self-install `.dmg` or `.zip` release assets containing `MediaFlow.app`.
- Window size and position are saved on quit and restored on launch.

### UI / chrome
- No main toolbar; the canvas stays reserved for media, with commands in menus and hotkeys.
- No photo/video badge — items just show their content

### Flow Library / TV mode
- `items` is now the full media library, while `visibleSlots` is the current screen slice.
- Floating Flow Library panel shows thumbnail previews of loaded media, highlights on-screen items, and supports click-to-select plus double-click-to-reveal.
- Maximum visible item count limits how dense the fullscreen wall becomes.
- Round-robin and random rotation modes cycle through the library on an infinite timer.
- Random rotation can optionally fill duplicate visible slots with the same source item.
- Hidden videos are paused while off-screen and resume only when they are configured to play when visible.

## Known issues / limitations

- **Layout can still repack.** The optimizer prioritizes filling the canvas, so adding/removing items can rearrange cells.
- **Playback files reference encrypted paths.** If source media is moved or deleted, that item cannot be restored from `.ivplayback`.
- **Embedded-key encryption is obfuscation against casual inspection.** It prevents plain JSON on disk, but anyone reversing the app can recover the bundled key.
- **Video metadata loading uses synchronous AVFoundation APIs.** It builds and runs, but Swift may warn about newer SDK deprecations.
- **Release artifacts must be Developer ID signed, notarized, and stapled before publication.** The scripts support that path for both the app and DMG.
- **Repository visibility remains unchanged.** Preparation is done for release hygiene, but GitHub visibility has not been changed.
